PERSONAL INVENTORY MOBILE — ACTUALIZACIÓN 1.1.0

1. Descomprimir este paquete.
2. Abrir la carpeta site_publish (en el ZIP de proyecto completo) o el contenido del ZIP de GitHub Pages.
3. Subir TODO el contenido a la raíz del repositorio personal-inventory en GitHub.
4. Reemplazar los archivos anteriores y confirmar los cambios.
5. Esperar a que GitHub Pages publique la actualización.
6. Abrir la PWA instalada en Android con conexión a Internet y esperar unos segundos.
7. En la PC, abrir Personal Inventory 1.1.0 y exportar un JSON nuevo desde Sistema y mantenimiento.
8. Transferir ese JSON al teléfono e importarlo desde la PWA.

El formato JSON ahora usa schema_version 2 para representar contenedores anidados.
La publicación de archivos no elimina el snapshot guardado en IndexedDB.
La importación del JSON nuevo reemplaza el snapshot anterior del teléfono.
La aplicación móvil sigue siendo de solo lectura.
